# Security policy

## Supported versions

Security fixes are made against the latest published version of Glance. Update to the newest release before reporting a problem that may already be fixed.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public pull request or discussion.

Use GitHub's [private vulnerability reporting form](https://github.com/atchad/glance/security/advisories/new). Include:

- the affected Glance and macOS versions;
- steps to reproduce the problem;
- the security impact;
- relevant logs or screenshots with credentials and personal data removed; and
- any suggested mitigation, if known.

The report will remain private while it is investigated. Please allow time for a fix before publishing details.
